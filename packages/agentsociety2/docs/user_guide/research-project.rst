管理研究项目
==============================

初始化工作区
--------------

保存仿真 LLM 配置后，在侧边栏点击“初始化工作区”，输入研究话题并回车。系统会创建 ``TOPIC.md`` 和基础目录；需要使用技能发现、模块查询等 API 时，再启动后端。

``TOPIC.md`` 是贯穿整个研究流程的核心文档，您可以随时手动编辑来补充研究描述、背景信息和研究方向。

与 Claude Code 协作
--------------------

点击侧边栏“AI 对话”，或在工作区终端启动 Claude Code，按客户端提示完成登录后描述研究需求。

进入对话界面后，用自然语言描述研究需求即可。平台会将研究流程中的关键操作封装为技能（Skill），Claude Code 会自动识别并调用。

推荐的研究流程
--------------

研究依次形成假设、实验配置、运行记录和分析报告；需要时可以回到前面的阶段修改设计，再由论文工具链接续写作。

各阶段说明见 :doc:`/skills`。

从问题到实验的完整操作顺序见 :doc:`/research_workflow`，外部数据的发现与准备见 :doc:`/datasets`。

工作区目录结构
--------------

随着研究推进，工作区会按需形成以下结构；初始化只创建基础目录，实验和报告在后续流程生成：

.. code-block:: text

   工作区/
   ├── TOPIC.md                          # 研究叙事中心文档
   ├── .env                              # 环境配置
   ├── papers/
   │   ├── literature_index.json         # 文献索引
   │   ├── <title>_<timestamp>.md        # 文献笔记
   │   └── full_texts/                   # 全文 PDF（如有）
   ├── user_data/                        # 用户数据
   ├── datasets/                         # 数据集
   ├── hypothesis_1/
   │   ├── HYPOTHESIS.md                 # 假设描述
   │   ├── SIM_SETTINGS.json             # 模块配置
   │   ├── experiment_1/                 # 实验 1（对照组）
   │   │   ├── init/
   │   │   │   ├── init_config.json      # 智能体与环境配置
   │   │   │   └── steps.yaml            # 仿真步骤
   │   │   └── run/                      # 运行产出
   │   └── experiment_2/                 # 实验 2（处理组）
   ├── presentation/                     # 分析报告
   │   └── hypothesis_1/
   │       ├── report_zh.md
   │       ├── report_zh.html
   │       ├── report_en.md
   │       ├── report_en.html
   │       └── charts/
   ├── synthesis/                        # 综合报告
   ├── paper/                            # 外部论文工具链产物
   └── custom/                           # 自定义模块
       ├── agents/
       ├── envs/
       └── skills/

技能、市场与 MCP
----------------

点击项目树中的 **技能**，进入统一管理页：

* **运行时**：发现、扫描和导入仿真 Agent 可用的行为技能。编写方法见 :doc:`/skill_guide`。
* **Claude**：查看研究助手技能，将所需模板同步到工作区。研究流程见 :doc:`/skills`。
* **市场**：管理技能源，浏览并安装第三方技能。
* **MCP**：添加外部工具服务，将连接配置同步到对应客户端；凭证按服务要求填写。

研究助手技能负责组织研究流程，运行时技能由仿真参与者按需激活，两者用途不同。查看、安装或同步技能后，仍需在对应助手或仿真中执行它。

分享工作区
----------

研究进行到可交接时，可在扩展侧边栏使用 **导出工作区**，把当前项目打包成压缩包发给同事：

- 导出列表会展示研究问题、假设与实验、文献、数据、分析报告、项目设置和技能；已有的关键内容默认勾选
- ``hypothesis_*`` 会完整包含实验配置（``init/``）和运行结果（``run/``），体积较大时可取消勾选
- **始终排除**：密钥与 ``.env``、虚拟环境、Git 历史，以及本地 IDE 状态（``.cursor`` / ``.vscode``）等
- 发出去之前，请确认你有权分享其中的论文、数据和第三方技能

对方在扩展中选择 **导入工作区** 后，依次选择分享包和保存位置，再输入新项目文件夹名。扩展会显示最终路径并新建目录，不会覆盖已有项目；导入后需要在配置页填写自己的模型密钥，才能继续运行。

管理文献
--------------

侧边栏 **文献库** 用于管理本地论文资产（与 CLI ``literature-search`` 主题检索互补）：

- 可 **上传 PDF**；扩展会尽量从文件内容扫描 DOI / arXiv ID，并调用公开接口补全标题、作者等元数据
- 也可 **粘贴 DOI 或 arXiv ID** 直接入库并查找元数据
- 索引与笔记写在 ``papers/``（如 ``literature_index.json``）；全文 PDF 通常落在 ``papers/full_texts/``
- 按主题批量检索、开放获取下载仍走文献技能 / MCP，见 :doc:`/skills`

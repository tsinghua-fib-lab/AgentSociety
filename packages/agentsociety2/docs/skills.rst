研究技能
========

研究技能帮助工作台中的研究助手推进文献检索、假设管理、实验设计、执行和分析。它们通过工作区文件衔接各阶段，便于研究者检查依据、修改配置并复用结果。

研究助手技能由扩展同步到工作区，供 Claude Code / Codex 使用；仿真参与者的行为技能则由 :doc:`/agent_skills` 中的运行时管理。首次研究的完整路径见 :doc:`/research_workflow`，输入数据准备见 :doc:`/datasets`。

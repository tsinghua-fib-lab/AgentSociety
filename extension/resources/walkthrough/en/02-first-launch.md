## Enter the Workspace

On Coder / code-server, use this checklist the first time you open a workspace or right after a restart.

### Workspace is still starting

If the portal briefly errors or sits on startup logs, extensions are usually still installing — **wait, then open the IDE again**:

![Workspace starting — please wait](../images/coder-workspace-starting.png)

### Trust the workspace

If the status bar shows **Restricted Mode**, extensions and tasks are limited:

![Restricted Mode in the status bar](../images/restricted-mode.png)

Open the actual research project folder, then use **Workspace Trust** to trust that folder. Avoid trusting the entire home directory simply to enable extensions:

![Trust the workspace](../images/trust-workspace.png)

### Switch UI language (optional)

To use a Chinese UI, change the display language:

![Switch display language](../images/gif/switch-to-chinese.gif)

You can also click the 🌐 button in the AI Social Scientist sidebar or status bar (or set `aiSocialScientist.language`) to switch the extension's UI language directly, independently of the VS Code display language.

After the folder is trusted and open, continue to the layout overview.

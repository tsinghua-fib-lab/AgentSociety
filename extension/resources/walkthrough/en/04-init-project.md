## Initialize a Research Project

**Save the Simulation LLM settings first** (API key in `.env`). The sidebar only offers **Initialize Workspace** after a key is detected.

You need a research workspace folder before you start.

### Create a folder

If you do not have a project yet, create an empty folder and open it in VS Code / code-server:

![Create a project folder](../images/gif/create-project-folder.gif)

### Initialize the layout

1. Save the Simulation LLM API base, key, and model on the config page.
2. Click **Initialize Workspace** in the sidebar, or run **AI Social Scientist: Initialize Research Project**.
3. Enter the research topic and wait for initialization; existing research files are preserved.
4. Expand `TOPIC.md`, then start the backend as needed. See [Configure LLM and Backend](05-configure.md).

For a continuous demonstration, see the [workspace initialization recording](https://github.com/tsinghua-fib-lab/agentsociety/blob/main/extension/resources/readme/research-workspace.gif). Follow the steps above if client labels differ.

The extension creates the base layout and writes `TOPIC.md`, a `.env` template, and related files:

```text
workspace-root/
├── TOPIC.md
├── .env
├── papers/
├── datasets/
├── user_data/
├── custom/
├── .claude/skills/
├── .agentsociety/       # project settings and workflow state
├── hypothesis_<id>/     # created by later workflows
├── presentation/        # analysis reports and assets, generated by later analysis workflows
├── synthesis/           # cross-hypothesis synthesis, generated by later synthesis workflows
└── paper/               # created when using paper-toolkit
```

You can also open an existing research workspace; the extension recognizes the layout.

### Command Palette

You can also trigger initialization from the Command Palette with **AI Social Scientist: Initialize Research Project**.

- `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
- Type `AI Social Scientist` to list extension commands
